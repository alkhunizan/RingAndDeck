# Fluent Emoji Flat artwork

The SVG illustrations in this folder are original, unmodified Microsoft Fluent Emoji Flat assets, redistributed under the MIT license in `LICENSE.txt`.

- Upstream: https://github.com/microsoft/fluentui-emoji
- Pinned revision: `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`
- Copyright: Microsoft Corporation
- Local SVG filenames match the existing Ring & Deck icon identifiers. The filenames do not claim to be upstream asset names.
- `manifest.json` records each exact upstream path, pinned source URL, source SHA-256, and the semantic accent used by the surrounding Ring & Deck UI. SVG colors are not recolored.

Action meanings guide the choices: a magnifying glass for search and review; a pen or pencil for writing; tools for building; a lady beetle for bugs; a calendar for scheduling; a stopwatch for focus; a folder for files; an open book for learning; a microscope or telescope for research; a shield or key for security; people for teamwork; a handshake for clients; charts for data; a robot for AI; and a light bulb for ideas. Review actions use a magnifying glass, including the legacy `swords` identifier.

All assets use `viewBox="0 0 32 32"`. SVGs are kept byte-for-byte identical to the pinned upstream files. Inline renderers should preserve fills and namespace any element IDs when embedding repeated assets in one SVG document.
