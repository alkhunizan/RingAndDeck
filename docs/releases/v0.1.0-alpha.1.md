# Ring & Deck 0.1.0-alpha.1

**Alpha prerelease.** The final Code Ring imports with a populated Home and opens More workflows in Logi Options+. Broader native acceptance, text insertion and physical-control testing remain incomplete.

Ring & Deck keeps reusable prompts and routine controls within reach. Instead of finding the same instruction again, open a workflow, choose an action and review its text in your preferred AI app before sending.

This first alpha contains six editable Windows profiles:

| Device | Profiles |
| --- | --- |
| Logitech Actions Ring | Code Ring, Work Ring, Flow Ring |
| 15-key Elgato Stream Deck | Code Workflow, AI Workflow, Browser Workflow |

## Included

- Native `.lp5` and `.streamDeckProfile` packages, with SHA-256 checksums.
- A shared graphite visual theme, category accents and licensed Lucide symbols.
- Editable JSON catalogs, reproducible build scripts and full action guides.
- 55 layout previews. These are generated guides, not device screenshots.
- Two browser-captured showcases of those designed layouts. They do not show native app imports or hardware operation.
- Two native Code Ring captures documenting the final Home and a previously rendered Plan & Scope folder with unchanged actions.
- MIT-licensed code and prompt adaptations, with ISC notices for Lucide artwork.

## AI and privacy

These profiles paste reusable instructions into the AI app you choose. They do not contain an AI model, call an AI API or request, store or transmit API keys. Your AI app manages its own sign-in, credentials, permissions, billing and data handling.

Text actions do not press Enter. Review the pasted prompt and fill in its placeholders before sending. Clipboard contents may be replaced. Keyboard shortcuts act immediately on the focused app. Public links open in the default browser and do not choose a personal account or browser profile.

## Installation

Back up your existing profiles, verify the checksums and import each candidate as a separate profile. Test text actions in a blank scratch document first. See the [setup checklist](https://github.com/alkhunizan/RingAndDeck/blob/v0.1.0-alpha.1/docs/SETUP.md).

## Validation and limits

All 13 local tests pass. The builder now uses the declared `System` mode and respects the Actions Ring limit of 8 Home controls and 9 controls per folder. Code Ring and Work Ring use More workflows for the remaining folders, retaining all 81 prompts each.

The final Code Ring UI import succeeds: Home shows 8 populated controls, and More workflows opens with Env & Tooling and Correct & Recover. Plan & Scope's 9 actions rendered in the preceding build and are unchanged. This does not verify deeper nested runtime navigation, text pasting or physical controls. Work Ring and Flow Ring UI imports remain unverified.

Stream Deck opens, but its UI has not responded to the attempted input, so no Stream Deck UI import is claimed. Original profiles have been backed up and their source files preserved. Other Stream Deck layouts and macOS are untested. See [validation](https://github.com/alkhunizan/RingAndDeck/blob/v0.1.0-alpha.1/docs/VALIDATION.md) and [known limits](https://github.com/alkhunizan/RingAndDeck/blob/v0.1.0-alpha.1/KNOWN-ISSUES.md).

The project contains no AI model or API client and stores no API keys. Test imports separately from working profiles; this prerelease still needs device acceptance.
