## Included

Ring & Deck keeps reusable prompts and routine controls within reach. Choose an action, review its text in your preferred AI app and submit it manually.

- Three Actions Ring profiles: Code Ring, Work Ring and Flow Ring.
- Three Windows 15-key Stream Deck profiles: Code Workflow, AI Workflow and Browser Workflow.
- 407 prompt definitions across the six profiles, 10 documented shortcuts and 14 public service links. Counts are unique within each profile; related prompts recur across profiles and Home shortcuts reuse definitions.
- Editable JSON catalogs, native packages, checksums, full guides and 55 generated layout previews.
- MIT-licensed code and prompt adaptations, with ISC notices for Lucide artwork.

## AI and privacy

The profiles contain no AI model or API client and do not request, store or transmit API keys. They paste instructions into your chosen app, which manages its own sign-in, credentials, permissions, billing and data handling.

Text actions do not press Enter. Review the prompt and replace placeholders before sending. Clipboard contents may be replaced. Keyboard shortcuts act immediately on the focused app. Public links use the default browser without selecting a personal account or browser profile.
