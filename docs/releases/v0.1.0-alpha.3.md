# Ring & Deck 0.1.0-alpha.3

**Draft release notes: unpublished Windows alpha candidate.** Publishing this file or building packages does not publish a release. The existing public release remains [v0.1.0-alpha.2](https://github.com/alkhunizan/RingAndDeck/releases/tag/v0.1.0-alpha.2).

All six profiles have colorful, familiar action pictograms: pens for writing, magnifiers for search and review, tools for building, clocks for focus and matching meanings across Actions Ring and Stream Deck. The Stream Deck glyphs now use a transformed SVG group so the native renderer can display them. Prompt text, action labels, navigation, identifiers, shortcuts and manual submission behavior are preserved.

## Candidate files

- Code Ring, Work Ring and Flow Ring: three `.lp5` packages for Logitech Actions Ring.
- Code Workflow, AI Workflow and Browser Workflow: three `.streamDeckProfile` packages for the Windows 15-key Stream Deck.
- `SHA256SUMS.txt` for the exact six candidate packages.
- Generated layout showcases. These are generated layout previews, not native app or hardware screenshots.

The source includes editable catalogs, 55 generated layout guides and original notices. Project code and prompt adaptations use MIT. The new Microsoft Fluent Emoji Flat illustrations retain Microsoft's MIT license; legacy Lucide source artwork retains ISC. Product names belong to their owners; this is an independent community project.

## Verification and limits

All 13 source tests and deterministic output checks pass. A clean rebuild reproduces all six MINI-updated handoff packages byte for byte. Independent archive review verifies the 257 Stream Deck images have no nested SVG, all 262 Ring icon templates match their PNGs, action/image references resolve and package/license hashes match. Comparison with public main `bf98287c53d034540ba4204ba4d220ffc9dc114c` preserves action behavior.

The MINI testing agent reports that all three fixed profiles imported into Stream Deck 7.6.0.23012's virtual 15-key editor and displayed every Home pictogram and title. That report covers configuration UI rendering only. Folder/Back navigation, text paste, hotkeys, links, physical keys and alpha.3 Actions Ring imports remain unverified. A duplicate Default-page import warning and tight native title spacing are documented and unchanged. See [the fix and evidence](../STREAM-DECK-ICON-FIX.md), [known limits](../../KNOWN-ISSUES.md) and [setup checklist](../SETUP.md).

## AI handling and installation

The profiles contain no AI model, API client or API keys. Your chosen AI app manages sign-in, credentials, permissions, billing and data handling. Text actions do not press Enter; review and submit manually. Shortcuts act on the focused app, and paste actions can replace clipboard contents.

Back up working profiles, verify SHA-256 hashes and import the candidate separately. Test text actions in a blank scratch document before using an AI composer. Windows, the 15-key Stream Deck and Logitech Actions Ring are the targets; other layouts and macOS are untested. Keep this release a prerelease until the remaining native and hardware checks are recorded.
