# Showcase fonts

Local Latin-subset WOFF2 fonts from the existing Azizme.com Next.js build: Source Sans 3 (Adobe), Spectral (Production Type) and IBM Plex Mono (IBM). Each is distributed under its bundled SIL Open Font License 1.1. Font sources: https://github.com/google/fonts/tree/main/ofl. No font is embedded in the native profile archives; native labels remain Arial for application compatibility.
