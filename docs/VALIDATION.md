## Local verification

- All 13 unit tests pass. They cover the complete selected collection, default pages, declared ring layout modes, Home/folder capacity, images, folder links, text behavior, ZIP reproducibility, stale artifacts, invalid catalogs, private data shapes and public URL validation.
- `python scripts/build.py` and `python scripts/build.py --check` pass. The latter rebuilds in memory and compares all generated bytes, including all six packages and their hashes.
- Ruff formatting and lint checks pass for the Python source and tests.
- All six ZIP archives pass CRC checks. Every folder/action/image reference inspected in the final archive resolves. Stream Deck Home pages each have 15 keys. Ring Home pages have 8 controls; workflow folders have 9 actions, and each More workflows navigation folder has 2 entries.
- There are 55 generated SVG previews. Earlier browser checks covered the original 53 guides, all six Home layouts and representative folders; those checks do not establish native device rendering. The two final showcase PNGs are complete 1279 by 722 browser captures of responsive designed layouts.
- Gitleaks scanned the public source tree and unpacked final artifacts with redacted reporting and found no leaks. A separate scan checked known personal references and original installation identifiers. No such values were found in public artifacts.
- Independent review completed. Private/alternate numeric URL acceptance and awkward generalized wording were corrected and re-reviewed.

The scanner cannot prove that every possible secret or sensitive fact is absent. These statements apply to the inspected candidate files, not future customizations.

## Native Logitech validation

The installed Logitech `LoupedeckService` library, version `6.4.1.3246`, successfully loads all three generated `ProfileInfo.json` documents through its native profile loader. Its keyboard parser resolves the seven Flow Ring shortcuts to the intended keys and modifiers.

The initial generated OS value `Windows` was rejected. The actual native enum is `Win`; correcting it made the loader accept all three profiles. A regression assertion preserves that value.

Native parsing alone missed a defect: the first Code Ring UI import displayed an empty Home because its layout mode was `main`, while the application declared `System`. The builder now uses `System`, and regression coverage checks the declared mode and Home references. A further capacity correction limits Home to 8 controls and folders to 9. Code Ring and Work Ring use More workflows to preserve all 81 prompts each.

The final Code Ring UI import succeeded. Home displays 8 populated icons; More workflows opens with Env & Tooling and Correct & Recover. Plan & Scope's 9 actions rendered in the preceding build, and those actions are unchanged in the final package.

## Showcase and publication boundaries

The two showcase PNGs are browser captures of designed pages using generated layout guides. They are not native app screenshots or evidence of a successful import. Native fonts, placement and geometry may differ.

Publication of [RingAndDeck](https://github.com/alkhunizan/RingAndDeck) and the `v0.1.0-alpha.1` prerelease is authorized. Upload and remote CI verification are still pending in this report. Keep the release marked as a prerelease until the outstanding native and hardware checks are recorded; publication alone does not satisfy them.
